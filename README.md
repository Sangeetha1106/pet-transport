# Sri Yogi Pet Transport

A responsive website for **Sri Yogi Pet Transport** – Door-to-door pet relocation services across India and worldwide.

## Features
- **Door-to-Door Pet Relocation**: International air flights, domestic train transport, climate-controlled road transfers, and boarding.
- **Interactive Route Explorer**: Visual travel routes with custom map animations.
- **Mobile Responsive**: Fully responsive layout optimized for all device sizes (mobile, tablet, desktop).
- **WhatsApp Integration**: Fast quote inquiries and booking via WhatsApp.

## Pages
- `index.html` - Home Page with Hero Slider, Service Overview & Live Tracker
- `about.html` - About Us, Personal Guidance & Safety & Care
- `services.html` - Detailed Service Breakdown & Routes
- `charges.html` - Transparent Itemised Pricing
- `how-it-works.html` - Step-by-Step Relocation Process
